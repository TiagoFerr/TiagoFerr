### 📌 Projeto em Destaque

#### 📰 [Mossoró Urgente — Portal de Notícias](https://mossorourgente.com.br)
Plataforma completa de notícias com tráfego real em produção, projetada para alta disponibilidade e carregamento instantâneo.

* **Frontend:** Next.js (SSR/SEO) + TypeScript.
* **Backend:** API REST em **Golang** para baixa latência e concorrência nativa leve durante picos de acessos.
* **Segurança:** Autenticação centralizada com **Keycloak** e controle granular de acessos (RBAC) para equipe de redação.
* **Armazenamento de Mídia:** Object Storage compatível com AWS S3 via **MinIO** para fotos e vídeos das notícias.
* **Banco & Infra:** **PostgreSQL** e **Docker** rodando em **VPS Linux** própria.
* 🌐 **Status:** https://mossorourgente.com.br *(acesso ao código mediante solicitação)*
